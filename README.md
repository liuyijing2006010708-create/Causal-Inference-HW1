# Monte Carlo模拟探索PSM-DID识别逻辑与理论边界

## 项目简介

本项目通过构建多维大样本的Monte Carlo模拟环境，深入探究了**倾向得分匹配结合双重差分法（PSM-DID）**在微观政策评估中的适用边界与理论底层逻辑。

以经典的劳动经济学场景（评估“就业培训项目”对低收入劳动者真实年收入的因果效应）为背景，本项目系统检验了在不同数据生成机制（DGP）下，传统DID、单独PSM 以及PSM-DID估计量的偏误（Bias）与均方根误差（RMSE），从而为因果推断方法的选择提供了坚实的数理与实证支撑。

## 核心亮点

* **严密的DGP场景设计**：独立设计了4种典型的数据生成机制，涵盖基础平行趋势（场景 A）、异质性时间趋势（场景 B）、时变未观测混淆（场景 C），以及**创新的非线性高阶（$X^2$）自选择模型误设（场景 D）**。
* **多方法横向对比与可视化**：全方位比对基础DID、控制变量DID、单独PSM与PSM-DID的表现，并产出倾向得分共同支持图与估计值核密度分布图。
* **严密的数理理论映射**：拒绝泛泛的教材复述，将模拟产生的数据表现（如方差膨胀、卡尺裁剪导致样本萎缩、跨区域外推偏误）与微观计量经济学底层理论（条件独立假设、条件平行趋势）进行深度绑定。
* **经典文献深度解构**：深度评价Heckman, Ichimura, &Todd (1997) 关于非参数匹配的理论神作，探讨其理论推导与本模拟实验结果的互证。

## 仓库结构

本仓库包含了本项目的完整研究报告、可视化图表、R代码、AI报告、论文材料、文献：

* `Report.md`：核心研究报告。包含完整的问题背景、Monte Carlo模拟设计、结果展示、理论解释、经典文献评价、结论以及研究局限与未来展望。
* `common_support_plot.png`：倾向得分共同支持区域分析图（展示`discard = "both"`条件下离群样本的精准修剪）。
* `density_plot.png`：各估计方法在四种场景下的核密度分布图（直观呈现偏误与方差的演变）。
* `R code.R`：完整代码展示，包括生成模拟数据、运行估计以及输出主要图表。
* `AI Report_Gemini.md`：完整AI使用记录。
* `Paper Materials.docx`：提交所评价论文的题名、作者、期刊、年份、DOI 或稳定链接。
* `Literature.pdf`：研究报告中所评价的Heckman, Ichimura, &Todd (1997) 文献原文。
